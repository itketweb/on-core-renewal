01 개요

3주 안에 시안 확정 → 고도몰 적용 → 검수

메인 1개와 서브 40개 화면은 이미 만들어져 있습니다. 남은 일은 컨펌, 실제 콘텐츠 교체, 고도몰 스킨 적용과 검수입니다.

범위

시안 확정 · 스킨 적용 · 데이터 정리 · 검수

메인 1 + 서브 40 화면을 고도몰 PC 스킨 chefs_choice 하나로 PC·휴대폰 모두에 적용하고, 상품 짧은 설명·게시판·배너·진열을 정리합니다.

범위 밖

이번에 하지 않는 것

장바구니·주문서·주문 완료·마이페이지 리뉴얼(고도몰 기본 화면 유지), 상품 신규 등록, 견적 시스템(dbk) 개발.

작업 위치

스킨 저장소 하나에서

저장소 itketweb/on-core.co.kr(비공개) — 시안은 renewal/(서버에 반영 안 됨), 스킨은 skin/front/chefs_choice/. 브랜치 feat/renewal-mockup. NAS 폴더는 열람용 사본.

완성의 정의 11/13에 다섯 가지를 모두 만족

  1. 시안 최종 컨펌11/12 최종 컨펌에서 확정
  2. 테스트 스킨 = 시안테스트 스킨 화면이 시안과 같음
  3. 폭 6종 점검 통과360 · 480 · 768 · 1024 · 1280 · 1440
  4. 실제로 접수됨견적 요청 · 바로 구매 · 회원가입 · 1:1 문의
  5. 되돌리기 준비이전 릴리즈로 바로 되돌릴 수 있음

반영 흐름 — 시안: pages-src/·renewal-plan.html 수정 → node - < _tools/build-pages.js 빌드 → 화면 확인 → 커밋. 스킨: skin/ 수정 → PR → main 에 merge = 테스트 스킨 자동 반영 → 확인 → 릴리즈(YY.M.D) = 운영 스킨 반영. 자세한 절차는 저장소 README.md.
