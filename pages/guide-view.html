워크스테이션 GPU, RTX A400과 A1000은 무엇이 다를까

설계·렌더링 용도별로 그래픽카드를 고르는 기준을 정리했습니다. 메모리 용량과 인증 드라이버가 핵심입니다.

서버2026-10-07

사내 문서 검색(RAG)이나 업무용 챗봇처럼 기업 안에서 쓰는 소형 언어 모델(sLLM)은 클라우드로 시작하기 쉽지만, 사용량이 늘수록 비용과 보안 부담이 커집니다. Lenovo ThinkSystem 서버로 자체 인프라를 꾸릴 때의 득실과 모델별 구성을 정리했습니다.

클라우드와 자체 서버 비교

항목퍼블릭 클라우드Lenovo ThinkSystem 자체 서버
초기 비용장비 도입비가 없어 시험(POC)에 유리서버 구매 비용이 든다
장기 비용토큰·인스턴스 비용이 사용량에 따라 크게 늘어난다고정 비용. 도입 10~14개월 무렵 클라우드 누적 비용을 넘어선다
보안기밀 데이터를 외부로 보내 보안 감사 부담이 생긴다내부 폐쇄망으로 운영해 사내 지식재산을 지킨다
운영네트워크 지연과 서비스 종속(Lock-in)이 생긴다자산으로 남고 3~5년 교체 주기를 직접 관리한다

온코어 기준으로 퍼블릭 클라우드 인스턴스를 2년 유지하는 것과 비교하면 자체 서버 구축 시 총비용(TCO)을 약 62% 줄일 수 있습니다.

처리량 비교

온코어 엔지니어링 랩 테스트 기준 (Llama-3-70B 4-bit 양자화 작업)

  • ThinkSystem SR675 V3 (NVIDIA L40S ×4) — 처리량 94%
  • ThinkSystem SR650 V3 (NVIDIA L4 ×4) — 처리량 72%, 가벼운 RAG에 적합
  • 일반 2U 제온 서버 (CPU 추론) — 처리량 18%, 병목이 심함

ThinkSystem이 sLLM에 맞는 이유

  1. GPU 확장 — SR675 V3는 모듈을 바꿔 단일 폭·이중 폭 GPU를 최대 8개까지 넣을 수 있어 처음 비용을 맞추기 쉽습니다.
  2. PCIe 5.0·DDR5 — 큰 모델의 가중치를 불러오고 긴 문맥을 처리할 때 지연을 줄입니다.
  3. 냉각·전원 — GPU를 가득 돌려도 성능이 떨어지지 않게 설계했고, 전원 이중화를 기본으로 제공합니다.
  4. XClarity 관리 — 웹과 모바일 앱으로 상태 확인, 펌웨어 업데이트, 장애 예측 알림을 지원합니다.

우리 회사에는 어떤 모델이 맞을까

  • 7B~13B 경량 모델 학습과 사내 문서 검색(RAG)이 중심이라면 — ThinkSystem SR650 V3 (NVIDIA L4 2~4개 또는 L40S 2개)
  • 70B급 오픈소스 LLM을 서비스하고 동시 사용자가 많다면 — ThinkSystem SR675 V3 (NVIDIA L40S 4~8개 또는 H100 NVL)

AI 서버는 GPU 사양만 보고 고르기 쉽지만, 실제 장애는 PCIe 대역폭 부족, 전원 용량 부족, 발열 제어 실패에서 생깁니다. 서버 단위로 검증된 구성을 고르는 것이 안전합니다. — 온코어 인프라 솔루션 기술팀
